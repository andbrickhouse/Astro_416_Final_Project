This repo contains the coing portion of my astro416 final project in a jupyter notebook, note that this code was written for use in google colab, and so will not function in its current form, as the data it requires is contained in my own google drive. The data in question are 1800 artificial exosatellite transit signals each defined by four parameters, mid-transit time, transit depth, slopes of ingress/egress, and transit duration. The purpose of my project was to use this data to replicate research results using machine learning methods.
